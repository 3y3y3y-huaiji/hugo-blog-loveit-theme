## SOCKS5 代理：网络穿透与安全隔离的必修课

如果说 SQL Server 支持是向左兼容数据，那么新增 SOCKS5 代理支持就是向右拓展网络。

在复杂的网络环境中，消息推送服务（如微信模板消息、短信网关等）往往受制于网络出口白名单限制。企业为了安全，通常会将内部应用部署在隔离的网络区域（DMZ）内。SOCKS5 代理的引入，让 WePush 具备了极强的网络环境适应能力。

从技术角度看，SOCKS5 不仅仅是一个简单的代理协议，它工作在会话层，不关心应用层的数据格式，这意味着它不仅能转发 HTTP/HTTPS 请求，还能处理各类基于 TCP 的自定义推送协议。更重要的是，SOCKS5 支持用户名/密码认证机制，这在多租户或跨网段推送时，提供了基本的鉴权保障。

在底层实现上，引入 SOCKS5 通常需要重构 HTTP Client 的初始化逻辑。以 Java 生态为例，从原生 Socket 到代理 Socket 的切换，需要对连接池进行深度配置，确保在批量并发推送时，代理通道不会成为性能瓶颈。
