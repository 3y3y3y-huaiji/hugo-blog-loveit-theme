```python
# audio_pipeline.py
# 一个简单的人声增强 + 自动字幕生成流程

import torch
from transformers import pipeline
import noisereduce as nr
import soundfile as sf

# 1. 加载原始录音
audio, sr = sf.read("raw_recording.wav")

# 2. 基于 RNNoise 的频谱减法降噪
cleaned = nr.reduce_noise(y=audio, sr=sr)

# 3. 使用 Whisper 自动生成字幕
asr = pipeline("automatic-speech-recognition", 
               model="openai/whisper-base")
result = asr("cleaned.wav", return_timestamps=True)

# 4. 输出 SRT 字幕文件
with open("output.srt", "w") as f:
    for i, chunk in enumerate(result["chunks"]):
        start = chunk["timestamp"][0]
        end = chunk["timestamp"][1]
        text = chunk["text"]
        f.write(f"{i+1}\n{start} --> {end}\n{text}\n\n")
```

这套流程的核心思路是：**把专业录音棚里的"硬件降噪"，替换成"软件 + AI 降噪"。** 对于非音乐类的语音内容（播客、有声书、课程），效果已经足够好。

## 三、声学处理的"穷人法"

买不起声学板？我用了一些"穷人法"声学处理，效果意外地不错：

### 1. 软装即声学

- **窗帘**：厚窗帘能吸收中高频反射。
- **地毯**：铺一块大面积地毯，地面反射立刻减少 50%。
- **抱枕和毛绒玩具**：堆在墙角，形成天然的"低音陷阱"。

### 2. 家具的妙用

- **书架**：摆满书的书架，是极好的宽频吸音体。
- **衣柜**：打开的衣柜内部，相当于一个天然的吸音腔体。
- **床铺**：厚床垫和被子，能吸收大量低频。

### 3. 麦克风摆位的艺术

- **距离**：嘴距麦克风 15-20 cm，太近会有近讲效应，太远会拾取更多房间声。
- **角度**：略微偏离正对方向（15°-30°），减少爆破音。
- **高度**：与嘴巴平齐，避免桌面反射。
