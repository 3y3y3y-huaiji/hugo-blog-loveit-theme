### 千禧年的“盗火者”：XviD 与 DivX 的罗曼蒂克消亡史

要理解 MPEG-4 Part 2 的历史地位，我们必须先回到那个带宽匮乏、存储昂贵的千禧年之交。彼时，MPEG-2 统治着 DVD，但互联网渴望一种能在 700MB 的 CD-R 光盘里装下一部接近 DVD 画质电影的魔法。

**MPEG-4 Part 2（正式名称为 ISO/IEC 14496-2）** 应运而生。它定义了“视觉对象”的编码框架，不仅涵盖传统的矩形视频，甚至野心勃勃地纳入了任意形状的视频对象和静态纹理。但在消费级市场，它被简化并神话为两个针锋相对的名字：**DivX** 与 **XviD**。

### 为何这次“过期”波澜不惊？—— 技术考古学的视角

今天的视频世界早已是 H.264、HEVC 甚至 AV1 的天下。MPEG-4 Part 2 专利过期之所以没有引发当年 MP3 专利过期时的行业震荡，核心原因在于其 **技术代差已不可逾越**：

1.  **宏块划分的原始性**：Part 2 的 ASP 主要依赖 16x16 或 8x8 的宏块划分。而 H.264 引入了可变块大小的运动补偿，最小可达 4x4。在复杂运动场景下，Part 2 的方块效应极其明显。
2.  **熵编码的瓶颈**：Part 2 主要依赖 Huffman 变长编码（VLC），而 H.264 引入了上下文自适应二进制算术编码（CABAC），仅在熵编码环节就能节省约 10%-15% 的码率。
3.  **环路滤波的缺失**：这是 Part 2 画质被诟病的硬伤。H.264 革命性地引入了环路去块效应滤波器（In-loop Deblocking Filter），使解码后的画面主观质量有了质的飞跃，而 Part 2 只能靠后处理滤镜，效果差且不可控。

    bestSAD = math.MaxInt32
    // 遍历搜索窗口
    for dy := -searchRange; dy <= searchRange; dy++ {
        for dx := -searchRange; dx <= searchRange; dx++ {

                        diff := int(curBlock.Data[y][x]) - int(refFrame.Data[refY][refX])
                        if diff < 0 {
                            sad -= diff
                        } else {
                            sad += diff
                        }

                }

}
