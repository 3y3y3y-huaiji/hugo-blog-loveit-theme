# 项目状态

更新日期：2026-11-12

## 项目概述

安卓人的个人技术周记。每周一 08:00（北京时间），GitHub Actions 采集公开 GitHub 活动（commits、PR、issue、release），通过 OpenCode CLI 接入 GLM 5.3 Flash 撰写轻松随笔型周报，校验后提交回 `main`，由 Cloudflare Pages Git 集成自动构建发布。正式内容位于 `content/posts/`，历史自动早报归档在 `content/archive/`。
